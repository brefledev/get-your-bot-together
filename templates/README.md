# Copy a useful starting point

Choose the file that solves the current problem. Keep your filled-in copies in your own private workspace. The assistant should adapt fields from available context and ask for information that materially changes the result.

| Template | Use it for |
|---|---|
| [PROJECT.md](PROJECT.md) | A project's goal, inputs, outputs and next action |
| [AGENTS.md](AGENTS.md) | Short working instructions for a project |
| [CLAUDE.md](CLAUDE.md) | Importing shared instructions where the Claude Code setup needs it |
| [PROCEDURE.md](PROCEDURE.md) | A repeatable task with defined inputs and checks |
| [HANDOFF.md](HANDOFF.md) | Moving current work into another chat or environment |
| [SOURCE-NOTES.md](SOURCE-NOTES.md) | Keeping exact quotes, claims and source locations together |
| [REVIEW.md](REVIEW.md) | Comparing the actual result with the original request |
| [CHANGE-PROPOSAL.md](CHANGE-PROPOSAL.md) | Showing a concrete setup change before approval |

Square-bracket fields describe information to fill. A proposal presented for approval should contain the actual task details.

For a complete example, read the [newsletter conversation](../examples/newsletter-session.md). For setup, use the [project-home recipe](../recipes/project-home.md).
