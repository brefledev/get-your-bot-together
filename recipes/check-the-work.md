# Check the work against the request

**Use this when:** you want to know whether the delivered artifact meets the assignment.
**Leave with:** a focused review, or a corrected artifact when revisions are authorized.

Give the [reviewer](../agents/reviewer.md) the original request, later corrections, actual current artifact, and original evidence.

> Compare this artifact with the assignment and later corrections. Cite any material gap and explain its effect. Check the sources you can access. A requirement that is already satisfied should remain satisfied. Return a clean result where appropriate, and identify evidence you could not obtain.

Use [REVIEW.md](../templates/REVIEW.md).

## Decide the role before the run

A reviewer examines the work and returns findings. A [finisher](../setup/finish-work.md) also makes authorized revisions and returns the usable artifact. Specify which result you want.

For exact requirements, run a suitable check: a calculation, required field, link target or build command. Use model judgment for meaning, relevance and writing quality.

## Check the reviewer

Give it the [brief and two small report drafts](../examples/reviewer/brief.md). One draft meets the stated requirements. The other uses the wrong comparison and adds an unsupported explanation. Compare with [the expected observations](../examples/reviewer/expected.md).

The reviewer should preserve correct work, distinguish omissions from preferences, and stop at the assignment's requirements. Keep results tied to the artifact version examined.

A saved role can be removed or restored from its previous copy. Review authority and publication authority follow their separate scopes.
