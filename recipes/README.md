# Choose a useful improvement

Start with a problem you recognize. Each recipe explains the result, includes resources to copy, and gives a small way to check the improvement.

| Recipe | Result | Start with |
|---|---|---|
| [Fix a repeated mistake](repeated-mistakes.md) | One specific change to a recurring task | A recent example |
| [Give the project a home](project-home.md) | A brief and simple working folders | The current assignment |
| [Find my actual words](find-my-words.md) | Exact quotes with source locations | A few authorized files |
| [Check the work against the request](check-the-work.md) | A focused review or corrected artifact | The request and output |
| [Make the next handoff useful](handoff.md) | A portable assignment and source packet | The latest work |
| [Save a repeatable method](repeatable-work.md) | A reusable procedure | A task you repeat |
| [Check a monthly report](check-a-report.md) | Date, arithmetic and source-field checks | Python and example JSON |
| [Add a useful hook](useful-hooks.md) | A scoped automatic check | A supported local runtime |
| [Prepare a draft and choose the finish](../workflows/draft-to-finish.md) | A complete draft for human or worker review | A real message |

**Using an assistant?** Give it [START-HERE.md](../START-HERE.md).

**Doing it yourself?** Choose a template, keep the working copy private, and adapt the example to your task. Configuration files live under setup/ for the relevant app.

A useful proposal names the exact change, where it belongs, the result you will receive, and how to undo a saved change.
