# Contributing

Help people complete a real task with less repeated correction.

A useful contribution includes the problem it solves, a complete fictional example, a copyable resource, and a check that shows the result. Keep the language accessible to someone beginning with an ordinary AI chat.

For runtime configuration, cite the current primary documentation and name the app, environment, file destination, event and expected behavior. Preserve existing settings when demonstrating installation. Include a removal or restore step.

Keep private transcripts, real customer data, credentials and local machine paths outside the repository. Use example.test addresses and fictional projects.

Run the tests and resource checker described in [TESTING.md](TESTING.md). For a bug report, include the relevant version, the smallest reproduction, expected result and actual result. Redact private inputs.

Public contributions use the [MIT License](LICENSE). The project owner reviews publication.
