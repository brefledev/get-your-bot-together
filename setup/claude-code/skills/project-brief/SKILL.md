---
name: project-brief
description: Produce a concise project brief from the owner's approved project notes.
disable-model-invocation: true
allowed-tools: Read, Grep, Glob
---

Use the owner's requested project and time period. Read only the approved
notes and files. Return completed work, decisions, blockers and next
actions, with a source location for each material claim.

Preserve the owner's wording for decisions and corrections. Identify
missing owners, dates or sources that affect the plan. Return the brief
in chat for review. Keep source files unchanged.
