# README graphics

The PNG files preserve the rendered typography. The SVG files contain editable text and vector shapes.

| Graphic | Dimensions | Files |
|---|---|---|
| Dark introduction | 1600 × 600 | [PNG](readme/intro-dark.png) · [SVG](readme/intro-dark.svg) |
| Light introduction | 1600 × 600 | [PNG](readme/intro-light.png) · [SVG](readme/intro-light.svg) |
| Wide workflow | 1600 × 960 | [PNG](readme/improvement-flow-wide.png) · [SVG](readme/improvement-flow-wide.svg) |
| Stacked workflow | 900 × 1800 | [PNG](readme/improvement-flow-stacked.png) · [SVG](readme/improvement-flow-stacked.svg) |

The README uses the dark introduction and selects the stacked workflow at viewport widths up to 600 pixels. The instructions and links also appear as selectable Markdown text.

Typography: [Calistoga](https://github.com/google/fonts/tree/main/ofl/calistoga), by the Calistoga Project Authors, with Georgia and Times New Roman fallbacks in the SVGs. The font uses the SIL Open Font License; font binaries are distributed through the linked source. Project graphics use the repository's [MIT License](../LICENSE).

The exports use fixed backgrounds, with warm paper, amber and teal against dark ink. SVGs contain local vector geometry and text; PNGs provide a consistent appearance across installed fonts.
