# Example: fewer missing sources

This is a fictional conversation showing the expected experience.

**Owner:** You keep leaving sources out of my newsletter. Can this help?

**Assistant:** The draft and correction you supplied show two factual claims without source links. We could add a source table while drafting, add a final source check, or use a separate reviewer. I recommend the first two as one small procedure in this chat.

**Owner:** Show me.

**Assistant:** Here is the proposed instruction:

> Draft from the sources approved for this newsletter. Keep each consequential factual claim beside its source in a short working table. Before returning the article, compare the final wording with those sources. Revise unsupported claims and flag material information that still needs an answer. Return the complete article with source links.

The table will contain the claim, supporting passage, source location and what it establishes. We can use it here immediately. Saving it for future newsletters would change your recurring writing procedure.

To check it, I will use a copy of the current draft with one deliberately unsupported claim. You should receive the corrected article and a short record of the claim caught. The original draft stays available.

**Owner:** Use it here. Show me the result before saving anything.

**Assistant:** I will apply it to this draft and return the revised article and source table.

The next result should contain that actual work. A proposal to save it comes after the owner can inspect what the method produced.

For persistent setup, the assistant reads the existing procedure, shows the exact addition, and asks the owner to approve that change. If a separate worker would add useful source access or checking tools, it explains that benefit before proposing a launch.
