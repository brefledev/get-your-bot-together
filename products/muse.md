# Muse: improve the task you already do

Start with one real example in your existing Muse conversation. Read [START-HERE](../START-HERE.md), then choose a relevant recipe. A source table, project brief or completed handoff can be useful directly in chat.

## Use the product's controls

[verified — [Muse permissions](https://www.meta.com/help/superintelligence/1385290430137537/)] Settings → Permissions includes connector and web-access choices. Ask for some actions requests approval before every write and important read actions. Always ask requests approval before every action.

Inspect the actual connector and explain the selected behavior in the context of this task. Show existing conflicts and the exact proposed change before saving.

For recurring preferences, use the available [identity and memory settings](https://www.meta.com/help/superintelligence/995796179982326/). A repeated procedure should preserve its exact inputs, steps and output.

## Finish useful work

Prepare the actual draft or resource and return it for review. If a configured worker would help, identify a supported launch route and give it the original request, current artifact and accessible sources.

With limited setup access, return the completed [handoff](../templates/HANDOFF.md) for the owner's chosen worker. The private handoff carries the user's files; public resources keep fictional examples.

Read back any saved change, try it on the intended task, and show how to restore the previous setting.
